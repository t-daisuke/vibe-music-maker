# Vibe Grid - グリッド型コードパッド楽器

## 概要
Vibe Gridは、Webブラウザ上で動作する直感的なグリッド型コードパッド楽器です。音楽理論の知識がなくても、自然なコード進行を簡単に作成・演奏できます。

## 主な機能
- 8x8のグリッド上でコードを配置・演奏
- キーとモードの選択（メジャー、マイナー、ドリアンなど）
- ダイアトニックコード、セカンダリードミナント、モーダルインターチェンジ対応
- テンション（9, 11, 13）やsus、add9などの拡張和音
- ループ録音機能（1〜16小節）
- エフェクト（リバーブ、ディレイ、コーラス）
- MIDIコントローラー対応

## 技術スタック
- フロントエンド: React + TypeScript
- 状態管理: Zustand
- UI: Tailwind CSS + Framer Motion
- サウンドエンジン: Web Audio API + Tone.js
- データ管理: IndexedDB

## 使い方
1. 依存関係のインストール
```bash
npm install
```

2. 開発サーバーの起動
```bash
npm run dev
```

3. ブラウザで `http://localhost:3000` にアクセス

## 操作方法
- グリッド上のセルをクリックしてコードを配置
- 左上の設定パネルでキーとモードを選択
- 中央のパネルで再生/停止、テンポ調整
- 右下のパネルでエフェクトを調整

## ショートカットキー
- Space: 再生/停止
- R: 録音開始/停止
- +/-: テンポ調整
- 1-8: ループ長設定
- Q: クォンタイズ切り替え

## 対応ブラウザ
